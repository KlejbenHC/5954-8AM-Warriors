What Makes a Hit? Spotify Song Analysis
A Python project by 8AM Warriors exploring how a song's audio features relate to its popularity. The project supports Lena Fischer, a talent scout interested in identifying promising songs and artists.
What the project covers
- Cleaning the Spotify dataset and checking repeated tracks, missing values, and zero popularity scores.
- Visualizing genre coverage, popularity distributions, and audio features such as danceability, energy, mood, and song length.
- Testing whether combining audio features helps identify high-popularity tracks using logistic regression, random forest, and gradient boosting.
Main takeaway
Individual audio features have weak relationships with popularity. Combining them improved the identification of popular tracks in preliminary testing, but the results do not yet establish reliable predictions of future hits or justify signing decisions on their own.

This repository contains the analysis code, the dataset, and this README.
